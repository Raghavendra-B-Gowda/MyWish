# MyWish Certificate Generator 🎓

MyWish is a simple and fast platform for designing, generating, and verifying professional certificates online. 

## Features
- **10+ Templates:** Choose from various professional designs.
- **Live Preview:** See changes instantly as you type.
- **QR Code Verification:** Automatically generates scannable QR codes.
- **Custom Branding:** Add your company logos and custom colors.
- **Easy Export:** Download as high-quality PNG or PDF.

## Tech Stack
- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, Shadcn UI
- **State:** Zustand

## How to Run

1. Clone the repository and go to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser.
